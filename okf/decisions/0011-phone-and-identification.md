# Decision

- LiveKit's phone number and a dispatch rule route calls to the single agent. The dialled number selects the agent profile.
- Phone sessions end after `PHONE_SESSION_SECONDS` (default 180) with a spoken warning 20 seconds before. Web sessions have no time cap.
- Each profile sets an identifier label (for example "admission number"), an optional second check and an attempt limit. Case tools stay locked until `identify_subject` succeeds.
- Keypad digits ending in `#` are passed to the agent as typed input.
- No SMS. Every case has a short code; `/case` shows the route when the code and identifier match.
- QR codes are generated by the backend per location and open `/a/{profile}?loc={location}`.

# Consequences

- The free number is a US number; callers elsewhere pay international rates.
- The attempt limit is per session.
